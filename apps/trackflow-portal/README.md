# TrackFlow Portal

Next.js application for Milestone 4 of the TrackFlow monorepo.

## Routes

- `/`: corporate website
- `/contacto`: B2B lead capture form
- `/internal-app`: internal entry dashboard wired to the Milestone 2 TypeScript module

## Commands

```bash
npm install
npm run dev
npm run typecheck
npm run lint
```

From the monorepo root you can also run:

```bash
npm run dev
npm run typecheck
```
